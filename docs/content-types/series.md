## What it is

A theme-led destination that collects related content: audio, video, editorial, shop content and external links, including numbered mixes / episodes where relevant. A Series-linked mix stays an ordinary mix with an added Series relationship and episode order. Homepage mix cards can be the entry point.

## Record

- Title, slug, description, artwork.
- Publish status.

## Relationships

- Mixes with episode number / order.
- Videos, articles, products, external links.
- Artists shown as responsible for individual pieces of content (derived from each item's own artist links).
- Events where applicable.

## V1 behaviours

- Create / edit / publish.
- Connect existing content; set episode order.
- Series page showing connected content and the people behind each item.

## Build note

Share the hub page structure with Artist Profiles. A separate Series implementation means duplicated functionality and a more expensive retrofit later.
