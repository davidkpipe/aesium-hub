## What it is

An individual page per artist: identity, role / status (resident or guest), location, bio, content shown through the Experiences grid and filters, events, releases, merchandise, related artists, Support the Artist links and a public follower count. Aesium manages every profile; artists send changes to Aesium and never edit their own page.

## Record

- Name, slug, role / status, location, bio, profile artwork.
- External links as defined fields (Spotify, Bandcamp, relevant social links).
- Publish status.
- Follower count (derived aggregate; follower identities stay private).

## Relationships

- Mixes, videos, editorial, events, releases, products.
- Related artists: derived primarily from shared genres across linked mixes, with collective or Series relationships adding context.
- Optional group / shared discovery presentation for artists with limited content, until enough content exists for a fuller individual profile.

## V1 behaviours

- Create / edit / publish profiles.
- Experiences grid and filters across the artist's content.
- Follow button and follower count.
- Same overall page structure retained when an artist has little content.

## Later

- Artist self-service (requires artist accounts, permissions and a new workflow).
